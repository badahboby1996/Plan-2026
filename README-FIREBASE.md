# ХЪСЪЛ · настройване на Firebase

Приложението работи веднага и без Firebase — тогава отметките в „Пазар“ се пазят само на текущия телефон.

За общ списък между двата телефона:

1. Конфигурацията от `Plan-2026` вече е поставена във `firebase-config.js`.
2. Във Firebase Authentication включи **Anonymous** вход.
3. В Authentication → Settings → Authorized domains добави `badahboby1996.github.io`, ако още го няма.
4. Във Firestore публикувай правилата от `firestore.rules`.
5. Всички файлове стоят в основната директория на хранилището. Не създавай папки и не преименувай файлове.

Когато връзката е успешна, в раздел „Пазар“ пише **Синхронизирано с телефона на Ширин**.
Докато няма връзка, пише **Локален режим · само на този телефон** и отметките пак се пазят.

Използваният път във Firestore е `hustle_family_app/badah/shopping_items`.
