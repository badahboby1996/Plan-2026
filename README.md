# ХЪСЪЛ · семейство Бадах

Progressive Web App за iPhone: хранителните планове на **Боби** и **Ширин**,
8-седмичният тренировъчен цикъл, всички рецепти и общият списък за пазар — на едно място,
на цял екран и без интернет.

**Адрес:** https://badahboby1996.github.io/Plan-2026/
**Инсталиране:** отвори адреса в Safari → *Сподели* → *Към началния екран*.

---

## Какво има вътре

| Раздел | Какво прави |
|---|---|
| **Днес** | Поздрав по час, следващото хранене с точния час, пръстен с приетите калории, протеин, брой хранения и вода. Днешната тренировка, подготовката за деня, серия дни, седмица от цикъла и мисъл за седмицата. |
| **Храна** | Превключване Боби / Ширин, седмична лента с дните, дневен резултат, бележка за подготовката и всички хранения. Докосване отваря пълната рецепта, кръгчето отмята изяденото. |
| **Фитнес** | 8-седмичната прогресия със състояние на текущата седмица, кинематичен кадър за деня, загрявка, упражнения с реални снимки и схеми, серии за отмятане и таймер за почивка със звук и вибрация. |
| **Пазар** | Пазар 1, Пазар 2 и месечният пазар с групи по магазин, напредък в проценти и синхронизация между двата телефона през Firebase. |
| **Рецепти** | Всичките 31 ястия от плана с търсене по продукт и филтър по вид хранене. |
| **Статистика** | Последните 7 дни: калории, вода, тренировки, серия дни и графика на теглото. |

### Интерактивност
- Отмятане на хранения, чаши вода, серии и продукти — всичко се пази на телефона.
- Плъзгане наляво/надясно сменя деня в „Храна“ и „Фитнес“.
- Бутонът **+** отваря бързи действия: вода, хранене, тренировка, тегло, рецепти, пазар.
- Долният лист се затваря с плъзгане надолу.
- Вибрация при всяко докосване, конфети при завършен ден, тренировка или пазар.
- Тъмна и светла тема; акцентът се сменя според раздела и профила.

## Файлове

| Файл | Роля |
|---|---|
| `index.html` | Обвивка на приложението и долната навигация |
| `styles.css` | Дизайн системата — токени, карти, пръстени, листове, анимации |
| `data.js` | Целият план: хранения, рецепти, тренировки, пазари, цитати |
| `app.js` | Изгледите, състоянието, таймерът, съхранението |
| `sw.js` | Service worker — приложението работи офлайн |
| `manifest.webmanifest` | Име, икони, цветове, бързи преки пътища |
| `firebase-config.js`, `firebase-sync.js` | Общият пазар между двата телефона |
| `workout-*.webp` | Снимките на упражненията (по 4 в кадър) |
| `app-icon-*.png`, `apple-touch-icon.png`, `app-icon.svg` | Иконите |

Съдържанието на плана е пренесено дословно — граматики, стъпки и грамажи не са променяни.

## Обновяване
Версията на кеша е в първия ред на `sw.js` (`VERSION`). При промяна на кода
вдигни стойността, за да получат телефоните новата версия веднага.

Настройката на Firebase е описана в [README-FIREBASE.md](README-FIREBASE.md).
